# Proofs — backtest / what-if / ceiling-audit audit (2026-09-24)

Audit: [`../../2026-09-24-backtest-whatif-ceilingaudit.md`](../../2026-09-24-backtest-whatif-ceilingaudit.md)

⚠ **These are Python PORTS, not the shipped VB.** The audit container had no .NET runtime,
so the relevant shipped functions were ported line-for-line (`CalcATR`, `CalcDMI` from
`Core/Indicators_Momentum.vb`; `CalcMTFGate` from `Core/Indicators_Structure.vb`; the
sequence path of `CoverageReport.ClassifySpan`; `WhatIfReplay.DeriveVerdict`; the Step-4
TRANSITIONAL arithmetic) and run on a SYNTHETIC 1-second tape. They are evidence of
mechanism, not a harness run. No `.vb` proof files were written, so nothing was renamed to
`.vb.txt`.

## Files

| File | What it is |
|---|---|
| `audit_proofs.py` | P1–P7. Self-contained. |
| `audit_proofs_lib.py` | `audit_proofs.py` truncated before the first `print` (ports + tape builder only). Generated by the one-liner below; required by the two MTF scripts. |
| `mtf_proof.py` | P3b first pass — MTF gate port, driftless pre-flush tape, 10 seeds. |
| `mtf_proof2.py` | P3b final — 20 seeds × 3 pre-flush drifts. This is the figure the audit quotes. |
| `out_*.txt` | Captured stdout of each script. |

## Run commands (exact)

From this directory, Python 3, standard library only:

```bash
python3 audit_proofs.py
# regenerate the lib (only needed if audit_proofs.py changes):
python3 -c "s=open('audit_proofs.py').read(); open('audit_proofs_lib.py','w').write(s[:s.index('print(\"=== P1')])"
python3 mtf_proof.py
python3 mtf_proof2.py
```

`audit_proofs.py` takes ~8 s. All seeds are fixed; output is deterministic.

## Assumptions a reader must carry

- P4's "live proxy" linearly interpolates the hourly funding anchors. That is an
  assumption about the ticker's `funding_8h`, not a measurement of it.
- P5 is a driftless walk at 1.8× the base 1m volatility, 1m bar-quantised on both arms, so
  the bias isolates the T+1/T+2 skip and nothing else.
- P6 ports only the sequence path of `ClassifySpan` (the uptime / scope / marker branches
  are not reached when the sequence path returns clean, which is the point).
