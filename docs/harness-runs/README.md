# Harness first-run baselines — TRACKED ON PURPOSE

Hand-written baseline reads, one per Jev harness first run, written **before** the
detector runs. Protocol: [`../harness-shadow-mode-protocol.md`](../harness-shadow-mode-protocol.md)
(trader-ruled 2026-09-21 UTC).

⛔ **These files are the only non-reproducible artefacts in the harness programme.** A
comparison report can be regenerated by re-running its tool. A baseline cannot be
written again once the seat has seen detector output on that data — there is no second
first run. That is why they are tracked and why they are not regenerable scratch.

Naming: `<harness>-<UTC-stamp>-baseline.json`.

Routine later re-runs use each harness's gitignored scratch path instead; only the
first run lands here.
