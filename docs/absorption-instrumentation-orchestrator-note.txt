IF YOU RUN ONLY ONE CHECK
------------------------------------------------------------------------------

  dotnet run --project verify/ordercheck > /tmp/h.out 2>/dev/null; echo "exit=$?"; grep -cE "^FAIL" /tmp/h.out; grep -c "ALL PASS" /tmp/h.out

Expect: exit=0, then 0, then 1.

Do NOT write it as `2>&1 | grep ...`. The A48 fixtures write diagnostics to stderr on
purpose; merging the streams interleaves mid-line and can swallow the terminal ALL PASS.

this build (it showed 308 PASS and no ALL PASS; the truth was 311 PASS, 0 FAIL, exit 0).
